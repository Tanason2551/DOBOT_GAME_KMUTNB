## 🎯 1. ภาพรวมภารกิจและสนาม 3x3

* **สนามตารางขนาด 3x3 (รวม 9 ช่อง):**
  * **8 ช่องรอบนอก (Slot 1 ถึง 8):** เป็นตำแหน่งวางก้อนลูกบาศก์เตรียมหยิบ โดยแต่ละช่องสามารถกำหนดสีได้อิสระ (🔴 แดง, 🟢 เขียว, 🔵 น้ำเงิน, 🟡 เหลือง, 🟠 ส้ม ฯลฯ)
  * **1 ช่องตรงกลาง (Center Slot):** พื้นที่เป้าหมายสำหรับวางซ้อนลูกบาศก์ขึ้นเป็นหอคอย
* **การซ้อนชั้นตามสี (Color-Based Stacking):**
  * ผู้ใช้เลือกสีที่ต้องการเรียงจากล่างขึ้นบน เช่น *ชั้น 1: สีแดง ➡️ ชั้น 2: สีน้ำเงิน ➡️ ชั้น 3: สีเขียว*
  * ระบบจะค้นหาตำแหน่งลูกบาศก์สีนั้นบนสนาม แล้วสั่งแขนกลเคลื่อนที่ไปดูดด้วยหัวดูดสุญญากาศ (Suction Cup)
  * ยกข้ามสิ่งกีดขวางที่ระดับปลอดภัย $Z_{\text{safe}}$ แล้วนำมาวางซ้อนกันที่จุดกึ่งกลาง โดยคำนวณระดับความสูงของแต่ละชั้น:
    $$Z_{\text{place}}(L) = Z_{\text{base}} + (L \times h_{\text{cube}})$$

## 🦾 2. สเปกแขนกล Dobot 4-DOF

ระบบถูกสร้างขึ้นมาตรงตามกลไก **4 Degrees of Freedom (4 แกน)** ของ Dobot (เช่น Dobot Magician / Magician Lite):

| แกนข้อต่อ (Joints) | ฟังก์ชันการทำงาน | ช่วงองศาการหมุน |
| :--- | :--- | :--- |
| **Joint 1 ($J_1$)** | ฐานหมุนซ้าย-ขวา (Base Yaw) | $-135^\circ$ ถึง $+135^\circ$ |
| **Joint 2 ($J_2$)** | ท่อนแขนหลักยกขึ้น-ลง (Rear Arm) | $0^\circ$ ถึง $+85^\circ$ |
| **Joint 3 ($J_3$)** | ท่อนแขนปลายพับเข้า-ออก (Forearm) | $-10^\circ$ ถึง $+95^\circ$ |
| **Joint 4 ($J_4$)** | มอเตอร์เซอร์โวหมุนข้อมือปลายแขน (Wrist Roll) | $-180^\circ$ ถึง $+180^\circ$ |

* **พิกัดคาร์ทีเซียน:** $X$ (หน้า/หลัง), $Y$ (ซ้าย/ขวา), $Z$ (ขึ้น/ลง), $R$ (มุมหมุนหัวดูด)

## 🌟 3. ฟังก์ชันเด่นของระบบ

1. **🎨 Interactive 3x3 Grid & Center Stack 3D:** แสดงสีก้อนลูกบาศก์ของแต่ละช่อง และช่องตรงกลางแสดงภาพหอคอยที่ซ้อนขึ้นมาทีละชั้นตามสีจริง
2. **✋ 3x3 Hand-Guided Teaching:** หน้าต่าง Teach ถูกจัดวางเป็นตาราง 3x3 ตรงตามสนามจริง แต่ละช่องมีปุ่ม **"📍 บันทึก"** และปุ่ม **"🎯 ทดสอบ"** ประจำช่อง กดคลิกเดียวบันทึกพิกัดทันที
3. **📡 Connection Watchdog & Latency Monitor (10 Hz):**
   - ตรวจวัดค่าความหน่วงสัญญาณ (Ping ms) และอัตราส่งข้อมูล (Hz) แสดงผลบน Header Bar
   - **Safety Interlock:** หากสาย USB หลุดเกิน 1.0 วินาที ระบบจะสั่งตัดการเคลื่อนที่ของภารกิจทันทีเพื่อความปลอดภัย พร้อมปุ่ม **"🔄 Reconnect"**
4. **📹 Live Camera Monitor (Logitech C270):** แสดงภาพสดจากกล้องพร้อมเส้นกากบาทและตาราง 3x3 Grid Alignment Overlay
5. **🎮 Full Manual Jog Control:** ขยับปรับแต่งตำแหน่งได้ทั้งแบบแกน Cartesian และแกน Joint พร้อมปุ่มทดสอบเปิด/ปิด Suction Cup
6. **🔤 Compact Typography:** ฟอนต์ขนาดกะทัดรัด (10px - 11px) สไตล์แดชบอร์ดอุตสาหกรรม พอดีกับหน้าจอ ไม่ต้องเลื่อนจอ

## 📦 4. การติดตั้งและเตรียมความพร้อม

เปิด Terminal บน Ubuntu แล้วรันคำสั่งติดตั้ง Dependencies เพียงครั้งเดียว:

```bash
# 1. ติดตั้งไลบรารีกราฟิกและ Serial ของระบบ
sudo apt update
sudo apt install -y libgl1 python3-serial

# 2. ติดตั้งไลบรารี Python สำหรับ GUI (PySide6) และกล้อง (OpenCV)
pip install PySide6 pyserial opencv-python --break-system-packages

# 3. ตั้งค่าสิทธิ์ให้ User เข้าถึงพอร์ต USB Serial (/dev/ttyUSB*)
sudo usermod -a -G dialout $USER
```
*(เมื่อรันคำสั่งเสร็จแล้ว หากเพิ่งเพิ่มกลุ่ม `dialout` แนะนำให้ Log out แล้ว Log in เข้าสู่ระบบใหม่อีกครั้ง)*

### ขั้นตอนการ Teach พิกัดสนาม 3x3:
1. ไปที่แท็บ **"📝 บันทึกสี & Teach พิกัด"**
2. กดปุ่ม Hand-Teach บนตัวแขนกล (ปุ่มเล็กๆ ใกล้หัวดูด) เพื่อปลดล็อกมอเตอร์ แล้วลากปลายหัวดูดไปแตะผิวด้านบนของก้อนลูกบาศก์ใน **ช่อง Slot 1**
3. เลือกสีก้อนลูกบาศก์ในช่องนั้น (เช่น 🔴 แดง) แล้วกดปุ่ม **"📍 บันทึก"** ในการ์ดช่อง Slot 1
4. ทำซ้ำกับช่องอื่นๆ จนครบทั้ง 8 ช่องรอบนอก
5. **ช่องตรงกลาง (Center Slot):** แนะนำให้ลากแขนกลไปแตะ **พื้นผิวโต๊ะ/ฐานรองตรงกลาง** แล้วกดปุ่มบันทึกของช่อง Center (เพื่อให้ระบบคำนวณระดับความสูงแต่ละชั้นจากความสูงลูกบาศก์ $h_{\text{cube}}$ อัตโนมัติ)
6. กดปุ่ม **"💾 บันทึกไฟล์พิกัด (Save JSON)"** ที่แถบด้านล่าง เพื่อบันทึกพิกัดเก็บไว้ใช้ถาวร

### ขั้นตอนการรันภารกิจซ้อนชั้น:
1. ไปที่แท็บ **"🎯 ภารกิจหลัก (Pick & Place)"**
2. กำหนด **"ความสูงลูกบาศก์ (h_cube)"** (เช่น 25.0 mm) — สังเกตว่าป้ายกำกับ `🎯 Z วาง` ของแต่ละชั้นจะคำนวณและอัปเดตแบบ Real-time ทันที
3. เลือก **"จุดอ้างอิง Z ของ Center"**:
   - `📍 พื้นผิวโต๊ะ/ฐาน (Base Ground)` *(แนะนำ)*: เหมาะสำหรับกรณีที่บันทึก Center บนพื้นผิวโต๊ะ ชั้นที่ 1 จะวางที่ $Z_{\text{base}} + 1 \times h_{\text{cube}}$
   - `📦 ผิวบนก้อนแรก (Top of 1st Cube)`: กรณีที่บันทึก Center บนผิวก้อนแรก ชั้นที่ 1 จะวางที่ $Z_{\text{base}}$
4. (ตัวเลือกเสริม) ปรับ **"ระยะชดเชยการวาง (Offset)"** หากต้องการให้หัวดูดกดแนบสนิทขึ้น (เช่น -1.0 mm)
5. กดปุ่ม **"➕ เพิ่มชั้น"** เพื่อเลือกลำดับสีที่ต้องการวางซ้อน (เช่น ชั้น 1: แดง, ชั้น 2: น้ำเงิน, ชั้น 3: เขียว)
6. กดปุ่มสีเขียว **"▶️ START MISSION"** แขนกลจะเริ่มหยิบก้อนลูกบาศก์ตามลำดับสีมาวางซ้อนเป็นหอคอยที่ช่อง Center ตามระดับความสูงที่คำนวณไว้อย่างแม่นยำ

## 📡 7. ROS 2 Topics & Services Reference

### Topics ที่ส่งออก (Published Topics)
| Topic Name | Type | รายละเอียด |
| :--- | :--- | :--- |
| `/dobot/joint_states` | `sensor_msgs/msg/JointState` | องศาของข้อต่อทั้ง 4 แกน ($J_1, J_2, J_3, J_4$) ในหน่วยเรเดียน |
| `/dobot/pose` | `geometry_msgs/msg/PoseStamped` | ตำแหน่งพิกัดปลายแขนกล ($X, Y, Z$ และ Quaternion) |
| `/dobot/status_json` | `std_msgs/msg/String` | ข้อมูลสถานะการทำงาน แรงดูด และพิกัดในรูปแบบ JSON |

### Services สำหรับสั่งการ (Available Services)
| Service Name | Type | รายละเอียด |
| :--- | :--- | :--- |
| `/dobot/home` | `std_srvs/srv/Trigger` | สั่งแขนกลทำ Home Calibration เซ็ตศูนย์ |
| `/dobot/emergency_stop` | `std_srvs/srv/Trigger` | สั่งหยุดฉุกเฉินทันที (E-Stop) |
| `/dobot/set_suction_cup` | `std_srvs/srv/SetBool` | ควบคุมหัวดูดสุญญากาศ (True=ดูด / False=ปิด) |
| `/dobot/clear_alarms` | `std_srvs/srv/Trigger` | รีเซ็ตข้อผิดพลาดและเคลียร์ Alarm |

## ❓ 8. การแก้ปัญหาที่พบบ่อย (Troubleshooting)

* **เปิดโปรแกรมแล้วขึ้น `No Qt GUI library found` หรือ `libGL.so.1: cannot open`: **
  - แก้ไขโดยรัน: `sudo apt install -y libgl1 python3-serial && pip install PySide6 --break-system-packages`
* **ไม่พบพอร์ต USB หรือขึ้น Permission Denied (`/dev/ttyUSB0`):**
  - เกิดจาก User ยังไม่มีสิทธิ์เข้าถึงพอร์ต ให้รัน: `sudo usermod -a -G dialout $USER` แล้วทำการ Log out จาก Ubuntu แล้ว Log in ใหม่อีกครั้ง
* **กด Start Mission แล้วแขนกลไม่ขยับ:**
  - สังเกตไฟสถานะมุมขวาบนของ UI ว่าเป็นสีเขียวหรือไม่ หากเป็นสีแดง ให้ไปที่แท็บ Connection แล้วกดปุ่ม Connect อีกครั้ง
  - ตรวจสอบว่าได้กดเปิดสวิตช์ Power และปลั๊กไฟ 12V ของ Dobot เสียบแน่นหนาดีแล้ว
